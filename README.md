I run a game server hosting company, write the platform that manages the servers, build the mods and
Discord bots the players actually touch, and operate the communities on top of it all.

It's a full loop — **infrastructure, product, and the people using it** — which means I ship things
that have to survive contact with real users at 3am, not just pass a demo.

**Currently running:** 13 Node services in production · 11 game server instances · 6 game titles · 10+ sites and apps · 1 person

### What I work on

**Infrastructure & Hosting** — Windows Server, nginx, PHP-FPM, MySQL/MariaDB. AMP game-panel
provisioning with per-customer role scoping, Cloudflare/SSL/DNS, mail, Stripe and PayPal billing
with the full invoice → suspend → reactivate lifecycle, and tiered backups with restore drills.

**Software & Tooling** — Mostly the layer that didn't exist yet: panels, bots, and management
platforms for games whose tooling stops at "here's a console." Node.js services, PHP web apps, REST
APIs, RCON/telnet/BattlEye/Web API integrations, live maps, in-game economies, and moderation tooling.

**Game Modding** — When tooling can't reach far enough, I go into the game itself. 7 Days to Die
C#/Harmony patches and XPath modlets, DayZ Enforce Script with PBO packing and signing, FiveM Lua
resources on Qbox, and cross-server character/inventory sync.
